Una aplicación web educativa y visual dedicada a la raza Rottweiler. El objetivo principal de este proyecto es poner en práctica maquetación web adaptativa, integración y optimización de imágenes `.jpg`, así como el uso de componentes de UI.

---

## 📌 Características Principales

* **Manejo de imágenes JPG:** Implementación y estructuración de galerías e ilustraciones visuales optimizadas en formato JPG.
* **Diseño Adaptativo (Responsive):** Uso del sistema de grid y componentes de Bootstrap para garantizar compatibilidad con dispositivos móviles y de escritorio.
* **Estilos personalizados:** Hoja de estilos CSS propia para complementar y personalizar el diseño base de Bootstrap.
* **Entorno de desarrollo linuxero:** Proyecto configurado y desplegado mediante terminal Ubuntu sobre Windows Subsystem for Linux (WSL).

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje de marcado:** HTML5
* **Hojas de estilo:** CSS3
* **Framework CSS:** Bootstrap 5
* **Entorno de desarrollo:** Ubuntu WSL (Terminal)
* **Control de versiones:** Git & GitHub
